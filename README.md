# 블로즈 모바일 피부 타입 테스트 (초안 0.1.0)

블로즈 자사몰(카페24)에 올릴 **모바일 전용 피부 타입 테스트**의 시제품이다.
문진 10문항 + 사진 간이 분석(선택)으로 5가지 타입(건성·지성·복합성·민감성·수분부족형)을 알려주고,
가입하면 상세 리포트·맞춤 루틴·쿠폰 안내를 보여준다.

순수 HTML/CSS/JS 단일 페이지이고 서버가 없다. **사진은 폰 안에서만 분석하고 어디에도 올리거나 저장하지 않는다.**

## 지금 단계

개발 지시서 12장의 **1단계(시제품 제작)** 까지 끝난 상태다. 카페24에는 아직 올리지 않았다.

| 단계 | 상태 |
| --- | --- |
| 1. 시제품 제작 | 완료 (이 저장소) |
| 2. 실제 폰 테스트 | 아직 — 아이폰·갤럭시에서 카메라 촬영을 확인해야 한다 |
| 3. 카페24 탑재 | 아직 |
| 4. 가입·쿠폰·픽셀 연결 | 아직 |
| 5. 소액 광고 테스트 | 아직 |

## 실행

카메라는 HTTPS 또는 localhost 에서만 열린다. 파일을 더블클릭해서 여는 방식(file://)은 안 된다.

```bash
python -m http.server 8123
```

그다음 폰이 아니라 PC 라면 `http://localhost:8123/skintest/?dev=1` 로 연다.

## 테스트용 주소 옵션

| 옵션 | 동작 |
| --- | --- |
| `?dev=1` | PC 에서도 테스트가 열린다. 사진 지표의 실제 측정값도 결과 화면에 표시된다 (기준값 맞출 때 사용) |
| `?login=1` | 시제품에서 로그인 상태를 흉내 낸다 (`?login=0` 으로 해제) |
| `?unlock=1` | 저장된 결과로 바로 이동한다 (가입·로그인 뒤 돌아오는 주소) |
| `?share=dry` | 공유 링크로 들어온 화면. 값: `dry` `oily` `combo` `sensitive` `dehydrated` |
| `?dev=1&answers=1,1,1,1,3,3,3,3,1,1` | 문항별 보기 번호를 넣어 결과로 바로 이동한다 |
| `&photo=high,mid,low` | (answers 와 함께) 사진 지표 3개를 흉내 낸다. 순서: 붉은기, 유광, 톤 |

### 5가지 타입이 나오는 답 조합

| 타입 | `answers=` 값 (Q1~Q10 보기 번호) |
| --- | --- |
| 건성 | `1,1,1,1,3,3,3,3,1,1` |
| 지성 | `4,3,3,3,3,3,1,3,3,2` |
| 복합성 | `2,2,2,2,3,3,3,3,2,1` |
| 민감성 | `3,1,1,3,1,1,3,3,4,3` |
| 수분부족형 | `3,4,2,2,3,3,3,1,4,4` |
| 건성 + 민감 경향 태그 | `1,1,1,1,1,3,3,3,1,1` |

## 파일 구조

```
index.html                 /skintest/ 로 넘기는 한 줄짜리 페이지 (깃허브 페이지용)
skintest/
  index.html               화면 S0~S6 마크업
  css/skintest.css         모바일 스타일
  js/config.js             문항, 점수, 판정 기준, 타입 문구, 제품 번호, 사진 기준값  ← 값은 여기서만 고친다
  js/app.js                화면 전환, 점수 계산, 결과 저장
  js/photo.js              카메라, 얼굴 인식(MediaPipe), 참고 지표 계산
  js/pixel.js              메타 픽셀 이벤트, UTM 저장
  js/qr.js                 PC 접속 시 QR 생성
  js/vendor/qrcode.js      QR 라이브러리 (qrcode-generator 2.0.4, MIT)
  img/                     제품 자리 표시 그림 (공식 이미지로 교체)
member/join_result.html    가입 완료 화면 흉내 + 카페24에 추가할 스크립트 덩어리
```

## 오픈 전에 채워야 하는 것

모두 `skintest/js/config.js` 에 `TODO` 또는 주석으로 표시돼 있다.

- **카페24 상품 번호 4개** (`products.*.productNo`) — 지금은 비어 있어 [상품 보기]가 자사몰 메인으로 간다
- **메타 픽셀 ID** (`pixel.id`) — 지금은 이벤트를 브라우저 콘솔에만 남긴다
- **공식 제품 이미지** (`products.*.img`) — 지금은 자리 표시 그림이다
- **추천 이유 문구** (`types.*.reasons`) — 초안이다. 상품 상세페이지 문구 안에서 다시 고른다
- **마스크팩 사용 횟수** — 제품 사용법 표기와 맞는지 확인한다
- **사진 지표 기준값** (`photo.thresholds`, `photo.quality`) — 임시값이다. 조명이 다른 사진 10장 이상으로 맞춘다
- **얼굴 점 번호** (`photo.landmarks`) — 실제 폰 테스트로 확정한다

## 카페24에 올릴 때

1. 모바일 스킨 최상위에 `skintest` 폴더를 만들고 `skintest/` 안의 파일을 올린다. 주소는 `/skintest/` 가 된다.
2. `blrose.co.kr` 도메인에서는 `config.js` 가 자동으로 카페24 경로(가입·로그인·상품 주소)를 쓴다.
3. 로그인 판별은 `skintest/index.html` 의 `module="Layout_stateLogon"` 표시를 쓴다. 현재 스킨의 모듈 이름과 같은지 확인한다.
4. `member/join_result.html` 은 통째로 올리지 않는다. 파일 안의 `▼▼▼ … ▲▲▲` 사이 덩어리만 기존 페이지 맨 아래에 추가한다.
5. 카페24 메타 연동이 `CompleteRegistration` 을 이미 보내는지 확인한다. 보내지 않을 때만 그 덩어리의 `SEND_COMPLETE_REGISTRATION` 을 `true` 로 바꾼다.
6. `skintest/index.html` 에는 초안이라 `<meta name="robots" content="noindex">` 가 들어 있다. 검색 노출을 원하면 지운다.

## 지시서와 다르게 한 것

- 문항 오타 2곳을 고쳤다: Q2 "겨은 번들한데" → "겉은 번들한데", Q7 "나쁨 때만" → "나쁠 때만".
- 쿠폰 발급 배너는 **가입 완료 페이지를 거쳐 돌아온 사람에게만** 보인다. 기존 회원이 로그인해서 볼 때는 신규가입 쿠폰이 발급되지 않기 때문이다.
- 밝기 검사에 "빛이 너무 강해요" 안내를 하나 더 넣었다 (너무 밝아 얼굴이 하얗게 날아간 경우).
- 폰의 뒤로가기 버튼이 페이지를 나가지 않고 이전 문항으로 가게 했다.
- 타입별 추천 제품은 확정 조합을 쓴다: 건성 앰플(강력추천)+마스크팩, 지성 크림, 민감성·복합성 3종, 수분부족형 앰플+마스크팩. 올인원 세트 카드는 3종을 모두 추천하는 민감성·복합성에만 보인다.
